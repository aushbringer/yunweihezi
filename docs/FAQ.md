# 常见问题（FAQ）

## 安装与启动

**Q：Windows 提示缺少 WebView2 / 启动白屏？**
安装 [WebView2 Evergreen 运行时](https://developer.microsoft.com/microsoft-edge/webview2/) 后重试。Win11 通常自带。

**Q：Linux 双击没有反应？**
在终端中执行查看报错；若为 WebKit 渲染问题，可尝试：

```bash
WEBKIT_DISABLE_COMPOSITING_MODE=1 ./openterm
```

**Q：杀毒软件报警？**
安装包未做代码签名，部分安全软件会拦截未知发行者。可将安装目录加入信任，或自行从源码构建。

## 密码与凭证

**Q：必须设置应用密码吗？**
不需要。v1.0.13 起默认免密码使用：首次启动自动生成本机随机密钥文件 `vault.key`，凭证照常 AES-256-GCM 加密落盘。

**Q：免密码模式下凭证安全吗？**
密钥文件与数据库同目录，**能访问该目录的人即可解密**。共享电脑或高安全环境请设置主密码。

**Q：已经用了很久，现在想设置主密码，旧凭证会丢吗？**
不会。设置时会用新主密钥重新加密所有已存凭证。

**Q：忘记主密码怎么办？**
无法找回（无后门）。只能删除数据目录重建配置库，已保存的凭证需要重新录入。

**Q：锁定后会话会断开吗？**
不会。锁定只是遮罩界面，后台会话保持连接，解锁后继续操作。

## 连接

**Q：支持跳板机吗？**
支持多级跳板链，在会话对话框「跳板机」中添加，每一跳可独立选择认证方式。

**Q：支持 SOCKS / HTTP 代理吗？**
支持 SOCKS5、SOCKS4、HTTP 代理出站。

**Q：支持 SSH1 / 老设备吗？**
**不支持 SSH1**，仅 SSH2。老式网络设备可用 Telnet / Rlogin / 串口。

**Q：支持 RDP / VNC 吗？**
不支持，本工具面向字符终端与文件传输，不做图形远程桌面。

**Q：支持 PKCS#11 硬件令牌 / 智能卡吗？**
暂不支持。

**Q：X11 转发怎么用？**
Windows 需先安装并启动 VcXsrv 或 Xming（监听 `127.0.0.1:6000`），macOS 需 XQuartz；勾选会话的「X11 转发」后运行图形程序即可。未安装 X Server 时终端会提示无法连接。

**Q：连接后中文乱码？**
确认远端 locale 为 UTF-8；终端已按 `xterm-256color` 协商，老设备可尝试调整远端编码或使用 `LANG=zh_CN.UTF-8`。

**Q：连接经常断开？**
适当增大「保活(秒)」（默认 30）；开启「断线重连」可自动重连。

## 使用

**Q：怎么把会话移到分组？**
鼠标按住会话行拖到分组区域即可；拖到空白处移出分组。

**Q：怎么一次给多台机器发命令？**
打开多个标签 → 标签栏开启「广播输入」→ 键入的内容会发送给所有未排除的标签。单标签点广播图标可排除。

**Q：如何粘贴长脚本？**
使用「撰写窗格」，可多行编辑、检查后再一次性发送，避免逐行触发远端执行。

**Q：SFTP 支持断点续传吗？**
支持。下载默认续传，上传可开启续传；传输队列可取消任务。

**Q：外部编辑器保存后没同步？**
单文件限制 32 MB、超时 12 小时；超过限制请用 SFTP 直接传输。

**Q：配置怎么迁移到另一台电脑？**
「导出」生成加密 JSON → 拷贝到新机器 → 「导入」并输入同一密码。

## 构建与开发

**Q：能从 Windows 交叉编译 Linux 包吗？**
不能。Tauri Linux 依赖系统 WebKitGTK，需在目标 Linux（如麒麟 V10）本机构建；见 [BUILD.md](BUILD.md)。

**Q：Python 脚本功能为什么不可用？**
该能力为可选编译特性（`--features python`），且运行环境需 Python ≥ 3.9 abi3 运行库。

**Q：如何提 Issue？**
请附上系统版本、OpenTerm 版本、复现步骤与日志（设置 `RUST_LOG=openterm=debug` 后重跑）。
