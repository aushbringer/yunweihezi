# OpenTerm 使用手册

适用于 v1.0.13。文档中的界面名称与软件内中文标签一致。

---

## 1. 首次启动

首次启动**无需设置任何密码**，直接进入主界面。会话凭证使用本机数据目录下自动生成的随机密钥（`vault.key`）加密存储，普通使用完全透明。

若你需要用口令保护凭证（例如共用电脑），点击顶部工具栏「**锁定**」，在弹出的对话框中设置主密码（≥ 6 位）。设置后：

- 之后每次启动需输入主密码解锁
- 已存在的凭证会自动用新主密钥重新加密，不会丢失
- 忘记主密码无法找回，请自行保管

数据目录位置：

| 系统 | 路径 |
|---|---|
| Windows | `%APPDATA%\com.administrator.openterm\` |
| Linux | `~/.local/share/com.administrator.openterm/` |
| macOS | `~/Library/Application Support/com.administrator.openterm/` |

目录内主要文件：`openterm.db`（SQLite 配置库）、`vault.key`（免密码模式密钥）、`logs/`（会话审计日志）。

## 2. 会话管理

### 2.1 新建会话

左侧「**＋会话**」。表单字段随协议变化：

| 字段 | 说明 |
|---|---|
| 名称 | 显示在会话树与标签页 |
| 分组 | 可留空（未分组） |
| 协议 | SSH / Telnet / Rlogin / Serial / 本地 Shell |
| 主机 / 端口 | 协议默认端口自动填充 |
| 用户名 | SSH / Rlogin 必填 |
| 认证 | 密码 / 键盘交互 / 公钥 / Agent |

**SSH 专属项**：私钥路径（支持 `.ppk`）、私钥口令、跳板机（可添加多级，每跳独立认证）、出站代理（SOCKS5/SOCKS4/HTTP）、保活秒数、断线重连、X11 转发。

**串口项**：串口、波特率、数据位、停止位、校验位、流控。

**本地 Shell 项**：Shell 类型与工作目录。

### 2.2 测试连接

SSH 协议下底部有「**测试连接**」按钮。它使用当前表单里填写的参数（**不保存**）真实建立连接并认证：

- 绿色：`连接成功,耗时 XX ms`
- 红色：失败原因（鉴权失败、超时、拒绝连接等）

编辑已有会话时，密码/私钥留空会自动读取已保存的凭证进行测试。

### 2.3 仅连接（不保存）

底部「**仅连接**」用当前参数直接打开临时标签页，不写入配置库，适合一次性登录。

### 2.4 分组与拖拽

- 「**＋分组**」新建分组
- 鼠标按住任意会话行，**拖到分组行或分组区域内**即移动进该分组
- 拖到会话树空白区域 = 移出分组（变为未分组）
- 删除分组时，组内会话保留并变为未分组

### 2.5 导入 / 导出

「**导出**」将分组、会话、凭证打包为加密 JSON（需输入 ≥ 6 位导出密码）；「**导入**」选择该 JSON 并输入密码还原。

## 3. 终端操作

| 操作 | 方式 |
|---|---|
| 连接会话 | 双击会话行，或点行尾 ▶ |
| 新建标签 | 连接多个会话即为多标签 |
| 关闭标签 | 标签上的 ✕ |
| **分离为独立窗口** | 标签栏「分离」按钮，可拖到副屏 |
| **广播输入** | 标签栏广播按钮开启后，键入内容同时发送到所有未排除的标签 |
| 排除某标签 | 点击该标签的广播图标切换 |
| **撰写窗格** | 多行编辑命令，确认后一次性发送（适合粘贴长脚本） |
| 十六进制查看 | 标签栏十六进制按钮 |
| 字体 / 主题 / 透明度 / 全屏 | 工具栏「终端」设置 |

终端设置项包括字号、字体、光标样式、主题配色、滚动缓冲、背景透明度、搜索高亮等。

## 4. 文件传输

### 4.1 SFTP 双面板

选中 SSH 会话后点工具栏「**SFTP**」，下方展开本地 / 远程双面板：

- 双击目录进入，`..` 返回上级
- 拖拽或使用上传/下载按钮加入传输队列
- 传输队列显示进度、支持**取消**；下载默认**断点续传**
- 支持新建目录、重命名、删除

### 4.2 外部编辑器

远程文件右键「用本地编辑器打开」→ 系统默认编辑器修改 → 保存后自动上传回远端（单文件 32 MB 上限，12 小时超时）。

### 4.3 SCP / FTP

- SCP：基于当前 SSH 会话，单文件快速上传下载
- FTP：工具栏「FTP」独立连接明文 FTP 服务器（默认不在工具栏，可在「布局」中添加）

## 5. 端口转发

工具栏「**隧道**」，需先连接一个 SSH 会话。

| 类型 | 说明 |
|---|---|
| 本地 (L) | 本机端口 → 经 SSH 主机 → 目标地址 |
| 远程 (R) | 远端端口 → 隧道回本机 |
| 动态 (D) | 本机开启 SOCKS5 代理 |

可「保存」转发规则，勾选自动启动后，该会话连接时自动建立隧道。

## 6. 自动化

### 6.1 触发器

工具栏「**触发器**」新建规则：正则/关键字匹配终端输出后执行：

- `highlight` 高亮匹配内容
- `alert` 系统通知提醒
- `send` 自动向会话回写内容（支持模板变量）
- `script` 执行本地脚本

规则可限定为全局或某个会话。

### 6.2 快速命令栏

工具栏「快捷命令」显示命令按钮栏，点击即在当前会话执行。可在面板内增删改命令、分组排序。

### 6.3 键盘宏

工具栏「**键盘宏**」：

- 录制一段按键序列，绑定组合键回放
- 或直接映射「组合键 → 发送文本」

全局快捷键在应用内任何位置生效（发送到当前活动会话）。

### 6.4 自定义工具栏

工具栏「**布局**」：勾选/排序要显示的动作按钮与快速命令按钮。

---

## 7. 日志审计

工具栏「**日志**」查看历史会话日志：开始/结束时间、字节数、文件位置。

- 「查看」内嵌预览尾部内容
- 「打开目录」在文件管理器中定位
- 删除可选是否同时删除磁盘文件

日志默认记录会话输出，敏感环境请评估后再启用。

---

## 8. 安全说明

- 凭证以 AES-256-GCM 加密存储，主密钥来自 Argon2id 派生
- 免密码模式下密钥文件与数据库同目录，**能访问该目录即能解密凭证**，请在可信设备上使用
- Telnet / Rlogin / FTP 为明文协议，界面会提示风险
- 导出文件同样使用口令加密，请使用独立强口令

## 9. 常见操作速查

| 我想… | 这么做 |
|---|---|
| 不设密码直接用 | 默认即是，直接使用 |
| 给凭证加密码 | 工具栏「锁定」→ 设置主密码 |
| 验证配置是否正确 | 会话对话框 →「测试连接」 |
| 把会话归类 | 拖动会话到分组上 |
| 一次给多台机器执行命令 | 打开多个标签 → 开启广播输入 |
| 粘贴长脚本 | 打开撰写窗格，编辑后发送 |
| 让命令输出报警 | 配置触发器 alert |
| 传大文件 | SFTP 面板 + 传输队列（支持续传） |
| 免安装随身带 | 使用 portable ZIP 解压运行 |
